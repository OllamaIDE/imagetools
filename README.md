# 📸 ImageTools SaaS — Browser-Based Image Editor

A powerful, 100% browser-based Image SaaS built with **React**, **TypeScript**, and **Tailwind CSS**. No servers, no uploads—complete privacy for your users.

---

## 🚀 Features

- **25+ Professional Tools**: Compression, Resizing, Cropping, Converting, Filters, and more.
- **Privacy First**: All processing happens locally in the user's browser using Canvas API & WebAssembly.
- **Icon-Driven UI**: Modern, minimalist, and fully responsive design.
- **Ad-Ready**: Integrated ad slots for easy monetization.
- **SEO Optimized**: Pre-configured meta tags, sitemap, and robots.txt.

---

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/modrao/imagetools.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Development
Run the development server:
```bash
npm run dev
```

---

## 📦 Deployment

### For PC Users (cPanel/Static Hosting)
1. Run the build script:
   ```bash
   .\prepare-deploy.ps1
   ```
2. Compress the `dist` folder into a ZIP.
3. Upload and extract in your `public_html`.

### For Mobile/No-PC Users
1. Fork this repository.
2. Edit `src/config/site.ts` directly on GitHub to change the name/links.
3. Connect your GitHub account to **Vercel** or **Netlify** for automatic deployment.
